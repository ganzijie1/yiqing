# 中国 2020–2022 防疫控制与开放时点模型

本仓库整理疫情传播、医疗容量、防控强度、经济损失、死亡损失和社会压力权衡的仿真代码
及结果快照。模型用于机制分析和反事实比较，不是医学建议，也不把未观测参数伪装成历史事实。

## 模型

- `simulate_epidemic_control.py`：分阶段传播、干预强度、医疗容量、聚集效应和 2022 年
  放开波次的基础动力学模型。
- `optimize_reopening_timing.py`：从 2020 年起扫描候选开放日期，将死亡、医疗挤兑、
  经济成本和舆情/社会压力纳入同一损失函数，并执行容量和聚集性敏感性分析。

## 目录

- `src/`：可执行源码。
- `artifacts/`：事件表、逐日仿真、开放日期扫描、摘要、图表和飞书 Markdown 文档快照。

## 运行

```powershell
python -m pip install -r requirements.txt
python src/simulate_epidemic_control.py
python src/optimize_reopening_timing.py
```

脚本将结果写入仓库根目录的 `outputs/`。历史快照位于 `artifacts/`，用于对照，不能把
旧文件时间戳当作新运行证明。

## 识别与解释边界

政策日期和公开事件可核验；接触率、聚集乘数、死亡风险、医疗容量损失、经济成本权重和
舆情压力权重需要数据估计或区间敏感性。所谓“最优开放日”只在给定损失函数、参数分布和
政策集合内成立。它不是脱离价值权重和不确定性的唯一历史答案。
